## [1.0.0] - 2026-08-21

### Added

- `uuid` command — generates a random UUID (v4).
- `string` command — generates a random string, with `--length`, `--lowercase`, `--uppercase` flags.
- `integer` command — generates a random integer in a range, with `--min`/`--max` flags (default `0`-`100`).
- `password` command — generates a random password, with `--length`, `--mixed-letters`, `--only-digits` flags.
